# Perfect Pi

A versioned Pi environment for full-stack software engineering.

## Layers

- Matt Pocock Skills: engineering methodology
- Pi extensions: execution, research, browser, LSP, processes, and UI
- Project skills: product verification and architecture context
- Prompt templates: explicit daily shortcuts
- MCP: opt-in external systems

## Setup

The live configuration is installed under `~/.pi/agent`. The source of truth for local resources is this directory. Third-party skills and packages remain upstream-managed and are recorded in `manifest.json`.

After changing resources in an active Pi session, run `/reload`.
